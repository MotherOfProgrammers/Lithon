What is Lithon?

A Python-flavored language built for speed from the ground up.

Every value has a known, fixed type decided before the program runs. No guessing, no dynamic dispatch, no boxed objects. That trade is what lets Lithon compile straight to native code, as fast as C, C++, and Rust.

Why Lithon?

Python is fast to write, not fast to run. Every number is a heap object, every + a runtime decision. Most fixes bolt speed on after the fact. Lithon asks a more direct question:

What if the language itself never allowed the slow path to exist in the first place?

No inference, no silent conversions, no interpreter overhead. If Lithon can't prove something is safe and fast, it won't compile.

One language, prototype to production. Python-like syntax, every value statically typed. Compiles to native code in the same class as C, C++, and Rust. No interpreter tax. Can't prove it's safe and fast? It won't compile. No silent slow paths.
