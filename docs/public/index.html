What is Lithon?

A Python-flavored language built for speed. Types are fixed before run time, so everything compiles straight to native code, no guessing, no boxed objects, no interpreter.

Why Lithon?

Python is fast to write, not fast to run. Lithon asks a more direct question:

What if the language itself never allowed the slow path to exist in the first place?

No silent conversions, no interpreter overhead. If Lithon can't prove it's safe and fast, it won't compile.

One language, prototype to production. Python syntax, every value typed. Native code in the class of C, C++, and Rust. No interpreter tax. Can't prove it's safe and fast? It won't compile.
