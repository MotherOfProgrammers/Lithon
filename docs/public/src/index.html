03 / Quickstart

From clone
to run.

Three commands. Zero dependency hunting. The fastest way to see Lithon’s promise for yourself.

Read the full README ↗
terminal
$ git clone https://github.com/MotherOfProgrammers/Lithon.git
$ cd Lithon
$ make -j$(nproc)
✓ Lithon v1.0.0-beta · x86-64 Native JIT
✓ Static Flow Verifier: Passed · 0 errors
$ ./lithon run examples/fib.py
Result: fib(30) = 832040
